# Simon Game 🎮

Welcome to the **Simon Game**, a nostalgic memory-based game built with HTML, CSS, JavaScript, and jQuery. This is a visually enhanced version of the classic where users must remember and repeat increasingly complex sequences of button presses, both in sound and color.

## 🌟 Features

- **Interactive Gameplay**: Memorize and repeat a sequence of button presses.
- **Sound Effects**: Each button has a unique audio cue.
- **Visual Feedback**: Background animation, button color transitions, and game-over flashes.
- **Particle Effects**: Unique shapes and colors burst out on button presses.
- **Responsive Design**: Works on both desktop and mobile devices.
- **Easy Restart**: Start or restart the game by pressing any key.

## 🕹️ How to Play

1. **Start the Game**: Press any key to begin.
2. **Watch Carefully**: A colored button flashes and its sound plays.
3. **Repeat the Pattern**: Click the buttons in the same sequence.
4. **Level Up**: Each round adds a new color to the pattern.
5. **Game Over**: One wrong click and the game restarts.

## 🧑‍💻 Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- jQuery 3.7.1

```

```

## 🎨 Visual Enhancements

- CSS gradients and transitions for a dynamic UI.
- Random particle shapes (stars, circles, diamonds) with color variation on button clicks.
- Responsive media queries ensure great gameplay across all devices.

## 🔊 Sound Files

Make sure to include the following `.mp3` files inside a folder named `sounds`:
- `red.mp3`
- `blue.mp3`
- `green.mp3`
- `yellow.mp3`
- `wrong.mp3`

## 🚀 Getting Started

1. Clone or download the repository.
2. Open `index.html` in any modern browser.
3. Press any key to start playing!
